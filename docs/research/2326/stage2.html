2.1BM — 안전한 것만 통과시키는 필터를 대리점으로 파는 고마진 소프트웨어

제품은 웹 필터 i-FILTER, 메일 보안 m-FILTER, 제로트러스트 접속 z-FILTER(2025.11 출시), 파일 암호화 FINAL CODE 등이며 모두 자체 개발임. 핵심은 '화이트 운용' — 위험 사이트를 골라 막는 대신 안전이 확인된 웹·메일만 통과시키는 허용 목록 방식으로, 이용자는 약 1,500만 명(26.3말), i-FILTER 경유 접속은 하루 약 190억 건임8. 판매는 대리점·SI 업체를 거치고 최근 직접 영업을 덧붙이는 중이며, FY26 매출총이익률 69.2%·영업이익률 44.2%임.

숫자를 읽는 열쇠는 매출 인식임. 설치형(온프레미스) 라이선스는 출하 때 대부분을 한꺼번에, 클라우드는 계약 기간에 나눠 매달 인식함. 그래서 FY26 계약액은 166.0억 엔(+57.1%)인데 매출은 108.35억(+8.5%)에 그쳤고, 남은 몫은 선수금으로 쌓여 78.0억(26.3말)에서 111.6억(26.9말)이 됨9. 선수금이 1~3년 뒤 매출의 선행지표임(편집 판단).
